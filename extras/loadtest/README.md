# Нагрузочный тест: шаблон

`k6-template.js` — смешанная нагрузка на путь чтения с ступенчатым ростом до `TARGET_RPS` (25% → 50% → 100%). Замените `MIX` своими эндпоинтами и заголовок авторизации — своим.

```bash
docker run --rm -e BASE_URL=http://host.docker.internal:8080 -e PROFILE=ramp -e TARGET_RPS=100 \
  -v "$PWD/loadtest:/scripts:ro" grafana/k6:0.54.0 run /scripts/k6-template.js
```

Правила:
- Гонять на изолированном стенде со своей БД, не на проде.
- Наполнить БД до реалистичного объёма: пустые списки отдаются нереалистично быстро.
- Эндпоинты с вызовами LLM мерить отдельно: их потолок — лимит провайдера.

Пример результата (ArcSpace, 05.11.2026, контейнер 2 vCPU / 1 ГБ, 200 проектов): 100 и 400 RPS без ошибок, p95 ≈ 6 мс.
