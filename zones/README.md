# Зоны: Green / Yellow / Red

| Зона | Что | Механизм |
|---|---|---|
| Green — без подтверждения | Чтение кода, поиск, локальная сборка, тесты по диффу, коммит в свою ветку | Разрешено по умолчанию |
| Yellow — с апрувом человека | `git push`, сборка Docker, внешние сетевые запросы, правка `.claude/*`, `opencode.json` | `ask` в настройках CLI |
| Red — технический запрет | `.env` и секреты, `git reset --hard`, `git clean`, `rm -rf`, force-push | `deny` в CLI + права ФС + серверная защита веток |

Строковый фильтр команд останавливает случайность, но не изолирует среду: `sh -c 'git reset --hard'` его обходит. Поэтому для Red Zone deny в CLI — только первый рубеж. Второй — права файловой системы (read-only монтирование харнеса и корня репозитория в контейнер агента), третий — защита веток на сервере.

Файлы:
- `claude-settings.json` → `.claude/settings.json` проекта (Claude Code).
- `opencode.json` → `opencode.json` в корне проекта (OpenCode).

Личные разрешения (`.claude/settings.local.json`) — в `.gitignore` и только для удобства. Не копите в нём allow-правила: на ArcSpace там набралось 491 разрешение и 0 запретов.
